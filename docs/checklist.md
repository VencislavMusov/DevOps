# Pre-release Checklist / Пред-релизен чеклист

Преди създаване на ново издание (Release) проверете следните точки:

- [ ] Всички автоматични тестове минават успешно (`pytest`).
- [ ] Проверката за стил и качество на кода минава без грешки (`ruff check .`).
- [ ] `README.md` е актуален и съдържа точни инструкции за стартиране.
- [ ] `docs/runbook.md` е проверен и описва актуалния порт и команди за диагностика.
- [ ] Всички архитектурни решения (`docs/adr/`) са описани и добавени в навигацията.
- [ ] `CHANGELOG.md` е обновен с промените за новата версия.
