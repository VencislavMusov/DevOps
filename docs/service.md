## Purpose / Предназначение

Тази услуга представлява REST API за управление на бележки. Тя предоставя базова функционалност, позволяваща на потребителите и клиентските приложения да създават, четат и достъпват текстови записи.

## Endpoints / Адреси

| Method | Path | What it does / Какво прави |
|---|---|---|
| GET | /health | Проверява състоянието на услугата (Health check) и дали тя е активна. |
| GET | /version | Връща информация за текущата версия на софтуера. |
| GET | /notes | Връща списък с всички налични бележки. |
| POST | /notes | Създава и записва нова бележка въз основа на подадените данни. |
| GET | /notes/{id} | Връща детайли за една конкретна бележка по нейния уникален идентификатор (ID). |

## Dependencies / Зависимости

За да работи, услугата се нуждае от активна база данни за съхранение на бележките и мрежова свързаност.
